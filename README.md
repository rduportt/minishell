# minishell

> My own little bash.

## What's inside

- Prompt and command history (readline)
- Pipes and redirections: `<` `>` `<<` `>>`
- Environment variable expansion and $?
- Signal handling: Ctrl-C, Ctrl-D, Ctrl-\
- Builtins: echo, cd, pwd, export, unset, env, exit

## Usage

```bash
make
./minishell
```
